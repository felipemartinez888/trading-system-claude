# Task brief M2-T2 — Simulator core (one simulator, two clocks)

- **Owner role:** Simulation & Risk Engineer (`sim-risk-engineer`)
- **Milestone:** M2 Historical data + backtest core
- **Branch:** `task/m2-t2`

## Goal
The order/fill/ledger engine shared by backtests and paper trading (ADR-0005), with conservative,
fully specified execution rules (SIMULATION §2–§4) and golden-trade tests. Pure Python, driven by
closed 1m `Bar`s from a `Clock`; no storage, no UI, no strategies in this task.

## Inputs (read, do not modify)
`CLAUDE.md`, `docs/SIMULATION.md`, ADR-0005, ADR-0012, `src/tsclaude/contracts/{market,signals,timeutil,ids}.py`.

## Deliverables — `src/tsclaude/sim/`
1. `clock.py`: `Clock` protocol yielding closed 1m bars in time order for a set of (market, symbol);
   `HistoricalClock(bars)` over in-memory sequences (validated: sorted, no duplicates, gaps reported
   rather than silently skipped); `mode` = BACKTEST / REPLAY / LIVE (live implementation comes in M3).
2. `costs.py`: `CostModel` (maker/taker fee rates per market as `Decimal`, slippage =
   half-spread + impact; in this task half-spread and impact come from a config/estimator interface
   with a deterministic default). Every cost component reported separately.
3. `orders.py`: order types MARKET (at next 1m open), LIMIT (fills only when a later bar trades
   **through** the price by ≥ 1 tick — touching is not filling), STOP (triggered when the 1m path
   reaches the stop; fill at the stop or **at the open if the bar gapped beyond it**), bracket
   children (SL + TP, OCO), time exit after N strategy bars, expiry (`valid_until_ms`).
   Tick size and lot size from an `InstrumentSpec` (rounding: price to tick in the adverse direction,
   quantity down to lot).
4. `fills.py`: deterministic fill engine on 1m OHLC paths. **Intrabar ambiguity rule:** if SL and TP
   are both reachable inside the same 1m bar → SL first, flag `ambiguous_bar=True`. Within a bar the
   assumed path for other decisions is O→(H or L nearer to O)→(the other)→C, documented.
   Execution never earlier than the next bar open after the decision time.
5. `ledger.py`: double-entry ledger with `Decimal` quantized to 1e-8 in the quote asset: cash,
   position cost, realized P&L, fees, funding (interface only; funding cash flows applied by caller
   at funding timestamps). Invariant: equity reconstructible from entries alone; a `reconcile()`
   method proves it.
6. `book.py`: `Book(name, starting_equity, cost_model, risk_hook)`: position sizing by fixed
   fractional risk (`risk_per_trade × equity / |entry − stop|`, clipped by max notional, lot size,
   min notional, available cash), long and short (short = USD-M perp, 1× notional cap), mark-to-market
   at every 1m close, equity curve, drawdown, trade records with R-multiple net of all costs,
   MAE/MFE in R, `ambiguous_bar`, exit reason. `risk_hook` is a callable that can veto an entry
   (stub returning allow in this task; the real risk engine is M3).
7. `engine.py`: `Simulator(clock, books, signal_source)` loop: on each closed bar, feed bar to open
   orders/positions (exits first, then entries for orders whose earliest execution time has come),
   then deliver the bar to the signal source, which may submit new signal-driven orders (they execute
   no earlier than the next bar). Emits a deterministic event list (dicts ready for the event store)
   whose SHA-256 over canonical JSON is the run fingerprint.

## Tests — `tests/unit/sim/` (must run locally: pure Python)
- **Golden trades** with hand-computed expected numbers in the test docstrings: market long TP hit;
  market short SL hit; limit touched-but-not-filled; limit traded-through filled; stop gap-through
  filled at open; SL+TP same bar → SL + ambiguous flag; time exit; expiry; fees maker vs taker;
  rounding to tick/lot in the adverse direction.
- **No look-ahead:** an order created from bar t's close can never fill at bar t's close or inside
  bar t; a signal source that "knows" the future bar cannot get a better fill (canary).
- **Ledger invariants** (deterministic randomized test with fixed seed, plus hypothesis tests in
  `tests/property/sim/` for CI): balanced entries, equity == reconstruction, never negative cash in
  spot long, size never exceeds limits.
- **Determinism:** same inputs → identical fingerprint; chunking the bar stream differently → same
  fingerprint.
- Drawdown and R-multiple calculations against hand-computed series.
