# Task brief M2-T4 — Backtest runner, run manifests and certified reports

- **Owner role:** Quant Engineer (`quant-engineer`) · **Effort:** medium
- **Milestone:** M2 · **Branch:** `task/m2-t4`

## Goal
One command runs a reproducible backtest: holdout-guarded lake data → features → strategy →
simulator → trades → `certify()` → graded report with a run manifest. This is what turns the merged
pieces into evidence.

## Inputs (read, do not modify)
`CLAUDE.md`, `docs/RESEARCH_PROTOCOL.md`, `docs/SIMULATION.md`, ADR-0005/0006/0009/0012 (all five
amendments), `docs/DECISIONS_PENDING.md` (L-04, L-07–L-10), `src/tsclaude/store/lake_reader.py`,
`src/tsclaude/sim/`, `src/tsclaude/research/stats/certify.py`.

## Deliverables (under `src/tsclaude/research/`, `src/tsclaude/features/`, `src/tsclaude/strategies/`)
1. **Features** (`features/`): pure windowed functions per ADR-0006 with declared warm-up (ATR,
   ATR percentile rank, rolling range high/low, EMA, volume z-score, realized vol), derived bars from
   canonical 1m (5m/15m/1h, UTC-aligned). Window-parity test (full-history vs trailing-window) and
   look-ahead canaries (mutating future bars never changes past values).
2. **Strategy interface** (`strategies/base.py`): frozen params, `strategy_id`, `version`,
   `params_hash`; on each closed strategy bar returns WATCH/CONFIRMED proposals with entry rule,
   stop, TP/exit policy. One **reference strategy** `bracket_reference` (simple, documented, not
   claimed profitable) to exercise the pipeline end to end.
3. **Runner** (`research/runner.py`): reads via `LakeReader(purpose="research")` only; runs the
   simulator with the cost model; writes `runs/<run_id>/manifest.json` (dataset ids, strategy id +
   version + params hash, prereg id if any, config hashes, code commit, seed, cost model version),
   `trades.parquet`, `equity.parquet`, `metrics.json`. Same manifest → identical metrics hash.
4. **max_loss_r default** (L-10): measure the instrument's worst gap-through stop loss in R on the
   development segment via the simulator, ×1.5; record value + source in the certificate. For
   bracket designs `max_win_r` = take-profit net of costs.
5. **Report** (`research/report.py`): metrics per RESEARCH_PROTOCOL/SIMULATION §8 incl. win rate with
   exact CI, p*, certified margin, n, n_eff, trial count, expectancy bounds, worst trade, beyond-stop
   count, ambiguous and spans_gap shares, cost share, cost stress ×1.5/×2, random-entry control,
   evidence grade A–D/X with reasons (cap grade on ambiguous/gap share > 5 %).
6. **Trial registry** (`research/trials.py`): every evaluated configuration recorded (SQLite table in
   state.db via the event store or a dedicated table); `n_trials` passed to certify comes only from it.
7. **CLI** `tsclaude backtest run --strategy … --symbols … --from … --to … [--seed]`,
   `tsclaude backtest show <run_id>`; API read endpoints `/api/backtests`, `/api/backtests/{id}`
   (with provenance `BACKTEST`) — Lead will wire the UI pages afterwards if you don't.

## Tests (no network; synthetic lake fixtures)
End-to-end run on a small synthetic lake; reproducibility (identical metrics hash twice); runner
refuses holdout without unlock; trial count increments; report fields present and correct on a
hand-checkable dataset; random-entry control runs; feature parity and canaries.

## Constraints
Write only under the paths above, `src/tsclaude/api/` (read endpoints only), tests, configs. Do not
modify `sim/`, `store/`, `contracts/`, `stats/` — request changes. Sandbox has no network; CI is the
real check. Scratch files prefix `m2t4_`. Conventional Commits + session trailer; push; final report.
