# Task brief M1-T1 — Binance live ingestion and bar builder

- **Owner role:** Data Engineer (`data-engineer`)
- **Milestone:** M1 Live tape
- **Branch:** `task/m1-t1`

## Goal
While monitoring is running, ingest Binance Spot and USDⓈ-M public market data for a configured
universe, produce **closed canonical 1m bars** with provenance, keep live best bid/ask and mark price,
detect and repair gaps, and report per-stream health — all as library components the runtime
supervisor (M1-T2, Platform) will start and stop. No UI work in this task.

## Inputs (read, do not modify)
`CLAUDE.md`, `docs/DATA_ARCHITECTURE.md` (all of it — limits, watermark rule, freshness budgets,
provenance), `docs/spikes/M0-spikes.md`, `src/tsclaude/contracts/{market,events,timeutil,ids,provenance}.py`,
`src/tsclaude/store/eventstore.py`, `src/tsclaude/runtime/sessions.py` (observation intervals).

## Deliverables (all under `src/tsclaude/marketdata/`, `src/tsclaude/quality/`, `src/tsclaude/store/`)
1. **REST client** `marketdata/binance/rest.py` (httpx.AsyncClient, injectable transport):
   spot (`api.binance.com`, fallback `data-api.binance.vision`) and USD-M (`fapi.binance.com`):
   server time, exchangeInfo (filters + status + rateLimits), klines (limit ≤ 1000 per call,
   pagination), futures premiumIndex, fundingRate, markPriceKlines.
   Weight-aware limiter seeded from `exchangeInfo.rateLimits`, corrected from `X-MBX-USED-WEIGHT-*`
   headers; 429 → honour `Retry-After`; 418 → stop REST and raise a typed `RestBanned` error.
   Never call private/signed endpoints (CI guard enforces this).
2. **WebSocket manager** `marketdata/binance/ws.py` (`websockets` library):
   - connection groups: spot (`wss://stream.binance.com:9443`, fallback `wss://data-stream.binance.vision`),
     futures `/market` (klines, markPrice@1s) and futures `/public` (bookTicker) at `wss://fstream.binance.com`;
     combined-stream mode `/stream?streams=a/b/c`;
   - outgoing control-message limiter (≤ 4/s spot, ≤ 8/s futures);
   - reconnect with exponential backoff + full jitter, capped; a connection-attempt budget
     (≤ 300 per 5 min per IP — stay far below);
   - **planned recycle** before 24 h (default 23 h): open the new connection, wait for its first
     message, then close the old one; duplicates during overlap are absorbed by the bar builder;
   - pings answered automatically by the library; record last-message time per stream.
3. **Parsers** `marketdata/binance/parse.py`: kline events (spot and futures), bookTicker,
   markPriceUpdate → internal typed messages. Reject malformed messages with a counted, logged error
   (never crash the connection loop). Normalize all timestamps to epoch ms.
4. **Bar builder** `marketdata/bars.py` per (market, symbol), 1m:
   - closed kline (`x == true`) → `Bar(source=WS_LIVE)`;
   - watermark: if a minute is not closed by `open + 60 s + grace` (default 5 s, server time) →
     REST fetch → `REST_RECOVERED` + `BAR_LATE` event; if REST does not return it → `GAP_DETECTED`;
   - identical duplicates ignored; differing duplicates → `BAR_CONFLICT` event (keep the WS-closed
     version, record both);
   - forming (partial) candle state kept in memory and exposed for the UI as `PARTIAL`, never stored
     as a bar.
5. **Live bar storage** `store/livebars.py`: table `bars_1m(market, symbol, open_time_ms, …, source,
   ingested_at_ms, observed_session_id)` in `state.db`, primary key (market, symbol, open_time_ms),
   idempotent upsert of identical rows only; query by range.
6. **Startup backfill** `marketdata/backfill.py`: for each (market, symbol) from the last stored bar
   (or a configurable lookback, default 3 days) to the last closed minute: REST klines → bars tagged
   `REST_RECOVERED` if the minute lies inside an observation interval, else `REST_BACKFILL`;
   `GAP_RESOLVED` events for gaps it fills; unrecoverable minutes stay as gaps.
7. **Quality monitor** `quality/freshness.py`, `quality/gaps.py`, `quality/clock.py`:
   per-stream states `CONNECTING → HEALTHY → STALE → DISCONNECTED → RECOVERING` with budgets from
   DATA_ARCHITECTURE §3 (configurable); a `STREAM_STATE_CHANGED` event on every transition; gap
   registry (open/resolved); server clock offset sampled every 5 min (median of 5); a
   `CLOCK_SKEW_CHANGED` event when |offset| crosses 1 s in either direction.
8. **Facade** `marketdata/service.py`: `MarketDataService(config, store, clock, http_transport=None,
   ws_connect=None)` with `async start()`, `async stop()`, `snapshot()` (latest closed bar, partial
   candle, best bid/ask, mark price, funding, per-stream state — each value as `Sourced` with the
   right provenance), and an async subscription for consumers (bar-closed, stream-state, gap events).
9. **Config** `configs/universe.yaml` (proposed v0 for M1: BTCUSDT, ETHUSDT, SOLUSDT on spot and
   USD-M; the rule-based top-10 comes in M2 when archives are available) and
   `configs/data_quality.yaml` (budgets, grace, recycle, backoff). Loader in `marketdata/config.py`.
   If you need YAML parsing add `pyyaml` to dependencies.

## Tests (no network; under `tests/unit/marketdata/` and `tests/integration/marketdata/`)
- Parser tests from realistic message fixtures (`tests/fixtures/binance/*.json`) written from
  Binance's documented payload formats.
- REST client with `httpx.MockTransport`: pagination, weight headers, 429 + Retry-After, 418.
- A **local fake WebSocket server** (`websockets.serve` on 127.0.0.1) driving the manager:
  normal flow, server drop → reconnect, planned recycle with overlap → no gap and no duplicate bar,
  malformed message → counted and skipped.
- Bar builder with a `ManualClock`: late close → REST recovery; missing in REST → gap event;
  conflict; partial never persisted.
- Backfill: correct tagging inside/outside observation intervals; idempotent re-run.
- Freshness state machine transitions and emitted events.
- Mark live-network smoke tests with `@pytest.mark.live` (skipped by default).
