# Task brief M3-T1 — Risk engine, live paper trading and restart safety

- **Owner role:** Simulation & Risk Engineer (`sim-risk-engineer`) · **Effort:** medium
- **Milestone:** M3 · **Branch:** `task/m3-t1`

## Goal
Paper trading on live bars through the same simulator (ADR-0005), gated by a deterministic,
fail-closed risk engine, with state that survives restarts.

## Inputs
`CLAUDE.md`, `docs/SIMULATION.md` (§5–§7), `docs/SIGNALS_AND_AGENTS.md` (lifecycle), L-04,
`src/tsclaude/sim/`, `src/tsclaude/marketdata/service.py` (subscriptions, snapshot freshness),
`src/tsclaude/runtime/supervisor.py`, `docs/tasks/M3-audit-failing-tests.py.txt` (two failing tests
from the M2-T2 audit).

## Deliverables
1. **Audit carry-overs (first):** R1 per-instrument funding clock; R2 fill-stage open-position count
   must not see exits later in the same minute; flag pending limits filled after a gap as
   `spans_gap`. Turn the two saved failing tests into passing tests.
2. **Risk engine** `src/tsclaude/risk/`: every rule of SIMULATION §6 (data freshness per symbol,
   clock skew, spread gate, cost-adjusted R:R, risk per trade, max concurrent, correlated exposure,
   gross exposure, daily loss limit, drawdown kill switch, signal validity), versioned config in
   `configs/risk.yaml`, pure function of (proposal, book state, market snapshot ≤ previous close),
   any exception → `RISK_BLOCKED`. Kill switch: halts book, flattens at next open, needs manual reset
   (event).
3. **LiveClock + paper books** (`sim/` live adapter): feed closed bars from the market-data
   subscription; books `baseline` and `benchmark` (equal-weight buy-and-hold); every fill/exit/funding
   is an event in the hash-chained store.
4. **Signal lifecycle** `src/tsclaude/signals/lifecycle.py`: WATCH → CONFIRMED → OPEN → CLOSED /
   VETOED / EXPIRED / INVALIDATED as events with the contract's allowed transitions; vetoed signals
   keep a shadow outcome.
5. **Restart:** rebuild book state from events; resolve open positions over backfilled 1m bars
   (`resolved_from_backfill`); expire signals whose validity passed during downtime; never create
   entries for unobserved minutes.
6. **Replay parity test:** a recorded live session replayed through the historical clock yields an
   identical ledger hash.

## Tests
Golden risk-rule cases (each rule alone blocks); fault injection (stale stream, exception in a rule,
crash mid-fill); restart resolution; replay parity; the two audit tests.

## Constraints
Write under `sim/`, `risk/`, `signals/`, `configs/`, tests. Wiring into the API/UI is a later
Platform task — expose a small `PaperTradingService` facade. Request contract changes (e.g. new
EventTypes for fills/risk) in your report. Sandbox has no network; CI is the check
(`scripts/ci/wait_ci.sh <sha>`). Scratch prefix `m3t1_`. Commit early, Conventional Commits +
session trailer, push, short final report.
