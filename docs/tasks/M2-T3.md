# Task brief M2-T3 — Statistics core for certified signal effectiveness

- **Owner role:** Quant Engineer (`quant-engineer`)
- **Milestone:** M2 (statistics foundation used by M2 reports and M4 selection)
- **Branch:** `task/m2-t3`

## Goal
Implement, from first principles and with exhaustive tests, the mathematics that decides whether a
strategy's win rate and expectancy are statistically real (ADR-0012, RESEARCH_PROTOCOL §4–§6).
This is the owner's top priority: "the highest win rate backed by reliable backtesting, pure
mathematics". Correctness over speed; every function documented with its formula and source.

## Deliverables — `src/tsclaude/research/stats/` (pure Python + NumPy only; no SciPy)
1. `binomial.py`
   - `binom_cdf(k, n, p)` and `binom_sf(k, n, p)` computed stably (log-space / regularized incomplete
     beta via continued fraction), exact for n up to at least 100 000.
   - `clopper_pearson(k, n, alpha, side)` exact interval (`side` ∈ two-sided, lower, upper), by
     solving the binomial tail equations with a robust root finder (bisection on [0,1] to 1e-12).
   - `wilson(k, n, alpha)` for display only.
   - `binomial_test_greater(k, n, p0)` one-sided exact p-value for H0: p ≤ p0.
2. `breakeven.py`
   - `break_even_win_rate(avg_win, avg_loss)` = L/(W+L) with input validation.
   - `bracket_break_even(b, cost_r)` = (1+c)/(1+b) for TP = b·R, SL = 1R, round-trip cost c in R.
   - `expectancy(p, avg_win, avg_loss)` and the identity check E = (W+L)(p − p*).
3. `multiple_testing.py`
   - `holm_adjusted_alpha(alpha, m, rank)` and `holm_bonferroni(p_values, alpha)` → reject flags.
   - `bonferroni_alpha(alpha, m)`.
4. `power.py`
   - `n_min_one_sided(p_star, p_alt, alpha, power)` normal-approximation formula from ADR-0012,
     **plus** `n_min_exact(...)`: smallest n such that the exact one-sided binomial test at level α
     rejects with probability ≥ power when p = p_alt (search over n; account for discreteness).
   - Normal quantile `norm_ppf` implemented (Acklam's algorithm refined by one Halley step) and
     `norm_cdf` via `math.erfc`.
5. `bootstrap.py`
   - `stationary_bootstrap_indices(n, mean_block, rng)` (Politis & Romano 1994).
   - `bootstrap_ci(values, statistic, alpha, n_resamples, mean_block, seed)` → percentile CI;
     deterministic for a given seed.
   - `optimal_block_length(values)` (Politis & White 2004 with Patton et al. 2009 correction) or a
     documented simpler rule if you justify it.
6. `sharpe.py`
   - `sharpe(values, periods_per_year)`; `probabilistic_sharpe_ratio(sr, sr_benchmark, n, skew,
     kurtosis)` and `deflated_sharpe_ratio(sr, n, skew, kurtosis, n_trials, var_trials)`
     (Bailey & López de Prado 2012/2014), with the expected-maximum-Sharpe formula using the
     Euler–Mascheroni constant.
7. `certify.py` — the decision function used by reports and selection:
   ```
   certify(outcomes_r: Sequence[float], *, p_star: float | None, alpha: float, n_trials: int,
           min_power: float, mean_block: float | None, seed: int) -> Certification
   ```
   where `outcomes_r` are net trade returns in R. Returns: n, wins, p_hat, exact two-sided CI,
   `p_lcb` (one-sided lower bound at Holm/Bonferroni-adjusted α over `n_trials`; if `mean_block` is
   given also the block-bootstrap lower bound, and the **more conservative** of the two is used),
   `p_star` (given, or computed from realized W/L), `margin_lcb = p_lcb − p_star`, expectancy with
   bootstrap CI, `n_min` for the observed effect, flags (`insufficient_n`, `margin_not_positive`,
   `expectancy_ci_includes_zero`), and `certified: bool` = all ADR-0012 admission conditions that are
   computable from outcomes alone hold. Zero-loss or zero-win samples must be handled explicitly
   (no division by zero; margin uses the bracket p* when given).

## Tests — `tests/unit/research/` (must run locally: NumPy is available, SciPy is not)
- Known exact values (hard-code reference numbers you derive by independent means in the test,
  e.g. direct summation with `fractions.Fraction` for small n): binomial CDF; Clopper–Pearson for
  (k,n) = (0,10), (10,10), (7,20), (530,1000) at α = 0.05; Wilson; one-sided p-values.
- Coverage simulation (property): for random p and n ≤ 200, the Clopper–Pearson interval covers the
  true p in ≥ 1 − α of simulated draws (it is conservative) — deterministic seed, tolerance stated.
- Monotonicity/edge properties with hypothesis: bounds within [0,1], lower ≤ p_hat ≤ upper, CI
  shrinks as n grows at fixed p_hat, adjusted α decreases with more trials.
- `norm_ppf` vs `statistics.NormalDist().inv_cdf` (stdlib) to 1e-9.
- Break-even identity E = (W+L)(p − p*) on random inputs.
- Power: `n_min_exact` ≥ normal-approx result is not guaranteed — test instead that at the
  returned n the exact rejection probability ≥ power and at n−1 (searching down a window) it is
  below, within discreteness tolerance.
- Bootstrap: determinism by seed; CI of the mean of i.i.d. normal data covers the true mean at about
  nominal rate in a small simulation.
- DSR: reproduce a published worked example if you can derive it exactly; otherwise test limiting
  behaviour (n_trials = 1 reduces to PSR against 0; DSR decreases as n_trials grows).
- `certify`: a 60 % win-rate bracket strategy (b=1, c=0.05) with n = 50 is NOT certified
  (insufficient n); with n = 2 000 it IS; a 90 % win-rate strategy with b = 0.1 is NOT certified
  (margin below break-even) — the "fake high win rate" trap the owner must never fall into.
