# Task brief M0-T4 — API, dashboard shell, Windows launcher

- **Owner role:** Platform & UI Engineer (`platform-ui-engineer`)
- **Milestone:** M0 Foundations
- **Branch:** `task/m0-t4`

## Goal
`tsclaude app` starts a localhost FastAPI server that owns an app session (SessionManager), serves a
React/TypeScript dashboard shell, exposes real backend state, and lets the user Start/Stop
monitoring (in M0, monitoring is only the lifecycle state — no market data yet). A Windows launcher
starts it with one double-click.

## Inputs you must use (do not modify)
- `src/tsclaude/contracts/*` (Lead-owned), `src/tsclaude/store/eventstore.py`,
  `src/tsclaude/runtime/{settings,sessions,logging}.py`, `src/tsclaude/cli.py` (it imports
  `tsclaude.api.server.run(settings) -> int`).
- Design docs: `docs/ARCHITECTURE.md` §4 and §7, `docs/DASHBOARD.md`, ADR-0008, ADR-0010.

## Deliverables
1. `src/tsclaude/api/server.py`: `run(settings: Settings) -> int` — configure logging, open
   EventStore at `settings.state_db_path`, verify the chain at startup (refuse to start monitoring if
   verification fails, but still serve the UI showing the failure), open a session, start a
   heartbeat task (every `settings.heartbeat_interval_s`), run uvicorn on `settings.host:port`,
   open the browser if `settings.open_browser`, and on shutdown (SIGINT/SIGTERM/Ctrl+C or `POST
   /api/app/quit`) close the session cleanly. Return 0 on clean exit.
2. `src/tsclaude/api/app.py`: `create_app(context) -> FastAPI` factory (testable without uvicorn).
   Endpoints (JSON, ISO-8601 Z timestamps; every metric-like value as `Sourced` from
   `contracts.provenance`):
   - `GET /api/status` → app version, session id, session started, monitoring state + monitoring id,
     chain integrity report, detected crash of previous session (if any), server time.
   - `GET /api/coverage` → observation intervals (from `observation_intervals`) and the unobserved
     gaps between them.
   - `GET /api/events?after_seq=&limit=` → recent events (for the System › Logs & audit page).
   - `POST /api/monitoring/start`, `POST /api/monitoring/stop` → state transitions; 409 on invalid
     transition; refused (423) if the chain failed verification.
   - `POST /api/app/quit` → graceful shutdown.
   - `GET /api/health` → liveness for the launcher.
   - `WS /ws/live` → pushes `status` messages on every state change and every heartbeat.
   Security: mutating requests require header `X-TSC-Token` equal to a per-launch random token
   (`secrets.token_urlsafe(32)`) that the server injects into the served `index.html` (e.g. a
   `<meta name="tsc-token">` tag), and an `Origin` (if present) matching
   `http://127.0.0.1:<port>` or `http://localhost:<port>`; otherwise 403. The WebSocket checks the
   token as a query parameter and the Origin.
   Static: serve `src/tsclaude/web/static/` (built bundle) at `/`; if the bundle is missing, serve a
   minimal HTML page that says the dashboard bundle is not built and shows `/api/status` JSON.
3. `frontend/`: Vite + React + TypeScript (strict) + TanStack Query, pnpm. Build output goes to
   `../src/tsclaude/web/static` (`emptyOutDir: true`). Contents:
   - Persistent **status bar**: monitoring state with Start/Stop button (disabled while a request is
     pending; shows errors), session uptime, chain integrity badge, previous-crash notice with the
     unobserved interval, placeholders for Spot/Futures stream status shown as `UNAVAILABLE —
     not implemented until M1` (never fake green).
   - Left rail with the five workspaces and their pages (DASHBOARD.md §1); every page renders a
     meaningful empty state stating what will appear and in which milestone.
   - System › Health page shows coverage intervals (observed vs not) from `/api/coverage`.
   - System › Logs & audit page lists recent events from `/api/events`.
   - A reusable `<ProvenanceBadge>` component covering every `Provenance` value; DEMO renders with a
     hatched watermark.
   - Dark-first, dense, accessible; colour-blind-safe up/down colours defined as CSS variables.
   - `pnpm test` with vitest + @testing-library for: ProvenanceBadge rendering every value; status
     bar showing STOPPED/RUNNING from mocked API; token header sent on mutations.
   - Do not add charting libraries yet (M1).
4. `scripts/TradingSystemClaude.cmd` (CRLF) and `scripts/TradingSystemClaude.ps1`: check that `uv`
   is installed (print install instructions otherwise), run `uv sync --frozen` if needed, then
   `uv run tsclaude app`. Plus `scripts/README.md` describing first-time setup on Windows in ≤ 3
   commands.
5. Tests `tests/integration/test_api.py` using FastAPI `TestClient` (no network): status reflects
   session; start/stop transitions and 409; token and Origin enforcement (403 without token, 403 with
   foreign Origin); 423 when chain verification failed (use a tampered temp db); coverage after a
   start/stop cycle; WebSocket rejects missing token; quit endpoint triggers shutdown callback.
6. `pyproject.toml`: you may add runtime deps only if needed (e.g. none beyond fastapi/uvicorn should
   be required) and dev deps for tests (`httpx` is already a runtime dep for TestClient).

## Constraints
- Write only under `src/tsclaude/api/`, `src/tsclaude/web/`, `frontend/`, `scripts/`,
  `tests/integration/`, and `pyproject.toml` dependency lists. Request contract changes in your report.
- **The development sandbox currently cannot reach PyPI or npm** (egress proxy denies them).
  System Python 3.13 has `pydantic` and `uvicorn` but not `fastapi`/`httpx`. You can run the core unit
  tests with:
  `PYTHONPATH=src:/root/.local/share/uv/tools/pytest/lib/python3.13/site-packages python3 -m pytest -q -p no:cacheprovider -o addopts="" tests/unit`
  and lint with `ruff check src tests` / `ruff format`. You cannot install fastapi, React or Vite
  locally: write the code carefully, keep it simple and conventional, and commit `pnpm-lock.yaml`
  only if you can generate it (otherwise leave it out; CI will generate it). The Lead will run
  everything in GitHub Actions (Windows + Ubuntu) and send you failures to fix.
- No market data, no fabricated numbers, no placeholders shown as healthy.
- Follow CLAUDE.md. Commit on your branch with Conventional Commits.

## Acceptance tests
- CI (Ubuntu + Windows): `uv run pytest`, `uv run ruff check`, `uv run mypy src` green;
  `pnpm install && pnpm test && pnpm build` green.
- Manual (owner, Windows): double-click launcher → browser opens dashboard → Start/Stop toggles state
  → close → reopen shows the previous session ended cleanly; killing the process → reopen shows the
  crash notice and the unobserved interval.

## Out of scope
Market data, signals, charts, settings persistence, packaging (PyInstaller).
