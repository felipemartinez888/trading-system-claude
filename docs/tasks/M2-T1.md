# Task brief M2-T1 — Historical archive importer and Parquet lake

- **Owner role:** Data Engineer (`data-engineer`)
- **Milestone:** M2 Historical data + backtest core
- **Branch:** `task/m2-t1`

## Goal
Import Binance public historical data (spot and USD-M, 2022-01-01 → present) into an immutable,
content-addressed Parquet lake that backtests read from, with every file checksum-verified and every
dataset reproducible. Plus the rule-based universe (D-04) computed from that data.

## Inputs (read, do not modify)
`CLAUDE.md`, `docs/DATA_ARCHITECTURE.md` (§2, §3, §5, §6), `docs/spikes/M0-spikes.md` (spot archive
timestamps switch to **microseconds from 2025-01-01**), `docs/RESEARCH_PROTOCOL.md` §2 and ADR-0009
(holdout guard), `src/tsclaude/contracts/market.py`, your M1-T1 code (`marketdata/`, `store/livebars.py`).

## Deliverables
1. `marketdata/archive/` — downloader for `data.binance.vision`:
   - monthly zips for complete months, daily zips for the current month, REST for the tail;
   - `.CHECKSUM` (SHA-256) verified before use; mismatch = hard error, nothing written;
   - spot and USD-M `klines` 1m; USD-M `markPriceKlines` 1m and funding rate history (archive if the
     M0 spike / listing confirms it exists, otherwise REST `/fapi/v1/fundingRate` paginated);
   - resumable, idempotent, polite (bounded concurrency, retries with backoff), cache of raw zips.
2. Parser: one kline CSV parser for both markets; **per-file timestamp unit detection** (ms vs µs by
   magnitude and file date) normalized to epoch ms; header-row tolerance; validation through the
   `Bar` contract (`source=ARCHIVE`).
3. `store/lake.py` — Parquet layout from DATA_ARCHITECTURE §5 (`market=/kind=/symbol=/year=/month=`),
   immutable parts, `dataset_id = SHA-256(sorted file hashes)`, `imports/<dataset_id>/manifest.json`
   (source URLs, checksums, row counts, time range, gaps found), and `catalog.duckdb` views.
   Add `pyarrow` and `duckdb` dependencies (and `polars` if you use it).
4. `store/lake_reader.py` — the **only** read API for research: `read_bars(market, symbol, start, end,
   *, purpose)` returning bars with source; enforces the **holdout guard** (ADR-0009): for
   `purpose="research"` any range touching 2026-01-01 → 2026-09-30 raises unless a
   `holdout_unlock` event exists for the given `prereg_id` + strategy hash; warm-up bars before the
   holdout are served. Add `EventType.HOLDOUT_UNLOCKED` via a contract change request (Lead adds it).
5. Data QA report per dataset: missing minutes (as gaps, never interpolated), duplicates, OHLC
   violations, zero-volume runs, cross-check of a sample of derived 15m/1h bars against native
   Binance 15m/1h archive klines.
6. Universe: `marketdata/universe.py` computing the D-04 rule (both spot and USD-M perps ≥ 24
   months before the snapshot, USDT-quoted, no stablecoin bases / leveraged tokens, `TRADING`,
   ranked by 90-day median daily quote volume, top 10) from lake data + exchangeInfo; output
   `configs/universe_snapshot_<date>.yaml` with the inputs' dataset ids.
7. CLI: `tsclaude data import --market spot|usdm --symbols … --from … --to …`,
   `tsclaude data universe --snapshot YYYY-MM-DD`, `tsclaude data verify <dataset_id>`.
8. Owner script `scripts/import_history.ps1` (+ `.sh`): imports the default universe 2022-01 →
   last complete month and writes a summary to `evidence/data/`.

## Tests (no network)
Recorded small zips + CHECKSUM fixtures (generated in tests from documented CSV formats): checksum
mismatch rejected; ms and µs files both normalize correctly (a 2024-12 ms file and a 2025-01 µs file
must produce contiguous bars); idempotent re-import gives the same dataset_id; manifest contents;
holdout guard refuses, allows warm-up, allows after unlock exactly once per prereg; QA report finds
injected gaps/duplicates; universe rule on synthetic data.

## Constraints
- Write under `marketdata/`, `store/` (new files), `configs/`, `scripts/`, tests. Do not modify
  `contracts/`, `sim/`, `research/`, `api/`.
- The sandbox cannot reach data.binance.vision, PyPI or npm; CI is the real check, and the real

- Follow CLAUDE.md; Conventional Commits + session trailer; push `task/m2-t1`; final report.
