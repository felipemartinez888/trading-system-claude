# Task brief M4-T1 — Preregistration tooling and hypotheses H1–H3

- **Owner:** Quant Engineer · **Effort:** medium · **Branch:** `task/m4-t1`

## Goal
Turn the hypothesis slate (RESEARCH_PROTOCOL §8) into frozen, committed preregistrations and
implemented strategies, ready to run the moment the owner's historical import lands.

## Inputs
`CLAUDE.md`, `docs/RESEARCH_PROTOCOL.md` (all), ADR-0009, ADR-0012 (amendments 1–5),
`docs/DECISIONS_PENDING.md` (L-07…L-10), `src/tsclaude/research/` (runner, trials, report, prereg),
`src/tsclaude/strategies/`, `src/tsclaude/features/`.

## Deliverables
1. **Preregistration schema + tooling** (`research/prereg.py` extension, `preregistrations/TEMPLATE.yaml`):
   fields `prereg_id`, `strategy_hash`, rationale, exact entry/invalidation/exit/Early-Watch rules,
   parameter search space, **trial budget**, universe snapshot (2025-01-01 research universe),
   timeframe, sides, cost model version, risk settings, splits, primary metric (certified margin per
   ADR-0012), rejection criteria, `max_loss_r` policy. `tsclaude research prereg validate|freeze
   <file>` computes the strategy hash from the implementation and refuses edits after freeze.
   Enforce the trial budget in the trial registry (M2-T4 TODO N5).
2. **Strategies** (each a pure strategy over causal features, with Early Watch and Confirmed Entry):
   - **H1** compression → expansion breakout (15m, 1h context), long/short.
   - **H2** trend pullback continuation (1h context, 15m entry), long/short.
   - **H3** range mean reversion (15m), only when expected move exceeds costs, long/short.
   - High-win-rate exit geometries (TP 0.5R–1.5R, time exits) included in every search space
     (ADR-0012).
   - Shorts only on USD-M (1× notional).
3. **Preregistration files** `preregistrations/H1-v1.yaml`, `H2-v1.yaml`, `H3-v1.yaml`, frozen with
   strategy hashes. Do not freeze before the Lead reviews them; leave `frozen: false` and the Lead
   commits the freeze.
4. **Walk-forward driver** (`research/walkforward.py`): anchored folds on the development segment,
   parameter selection on train only by the preregistered objective, purge/embargo of one max holding
   period, single validation evaluation of the selected configuration, stitched OOS report; every
   evaluated configuration counts as a trial.

## Tests
Synthetic-lake end-to-end for each hypothesis; strategy causality canaries; walk-forward never uses
test-fold data for selection (canary); trial budget enforced; freeze refuses edits.

## Constraints
Write under `research/` (not `research/stats/`), `strategies/`, `features/`, `preregistrations/`,
`configs/`, tests. Request changes elsewhere. CI is the real check. Scratch prefix `m4t1_`. Commit
early, Conventional Commits + session trailer, push, short final report.
